# 文件夹结构：通用写法和两个例子

## 通用写法

```
项目名/
  00_项目/            ← 共用：规则台账、已定设定表、进度摘要、负责人备忘、跑法、交接
  <单元前缀>N/        ← 每个单元一个文件夹
    N_<步骤1产物>.md
    N_<步骤2产物>.md
    ...
    复核/
```

定文件名时三条：

1. **一步一个产物文件**，名字说出“这是哪一步的什么”，下一步才能凭文件名判断上一步做没做完。
2. **带单元编号前缀**（`3_脚本.md`），文件被单独发出去也知道属于哪个单元。
3. **说明文件和产物分开**：产物给下一步读，说明（改了什么、待人定什么）给人看。

## 例子一：系列短视频（虚构项目《雾港来信》）

```
雾港来信/
  00_项目/
    规则台账.md
    已定设定表.md      ← 人物：邮差阿岚、灯塔看守老周；港口地图
    进度摘要.md
    负责人备忘.md
    素材登记表.md      ← 所有常驻素材及状态：待生成／已生成／已批准
    费用账本.json
  第N集/
    N_原稿.md          ← 负责人给
    N_脚本.md          ← 第 1 步
    N_脚本说明.md      ← 第 1 步：改了什么、【设定】【待定】
    N_素材需求.md      ← 第 2 步
    素材图/
    N_镜头表.md        ← 第 3 步
    N_生成记录.md      ← 第 4 步：每个镜头的提交、费用、AI 粗看
    视频/
    复核/
```

## 例子二：多轮迭代的文档或代码项目（虚构项目“仓库管理手册”）

```
仓库管理手册/
  00_项目/
    规则台账.md
    已定设定表.md      ← 术语表、读者是谁、章节划分
    进度摘要.md
    负责人备忘.md
  第N章/
    N_大纲.md
    N_初稿.md
    N_修改说明.md
    N_定稿.md
    复核/
```

代码项目可以把 `第N章/` 换成 `迭代N/`，产物换成 `N_需求.md`、`N_设计.md`、`N_测试报告.md`；代码本身仍在仓库里，这里只放交接文件。
