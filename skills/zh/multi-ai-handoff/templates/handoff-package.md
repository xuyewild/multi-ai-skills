# 交接包模板

派活或派复核时用一条消息发出。**给路径，不给结论。**

```markdown
## 先读
- 加载 skill：<skill 名或路径>（版本 / 仓库提交号：<SHA>）
- 项目规则：00_项目/规则台账.md#R012,R031（只列本次用到的编号），跑法文件：<有就写，没有写“无”>
- 规则冲突时以规则台账为准

## 目标
<负责人原话，带出处和日期；锁定项逐条列出>

## 输入
- 待处理 / 待审文件：<路径>
- 必读上下游：<路径>
- 工具报告（不是结论）：<脚本输出的路径>

## 产出
- 写到：<路径，固定文件名>
- 完成条件：<怎样算做完>

## 范围
- 这次做：<……>
- 这次不做：<……>
- 返工轮次：第 <N> 轮；上一份记录：<路径>（修订版才写）
```

## 不要写

- “已通过”“应该没问题”“上一轮基本 OK”
- 只附作者自己写的总结，不附原文件
- 让对方“顺便”做范围外的事
