# 复核闸门用法

`scripts/review_gate.py` 只做一件事：**记下“谁在什么时候复核了哪一版文件、结论是什么”，下一步开工前核对文件有没有变。** 它不判断内容好坏，内容由复核者判断。

## 一次完整的交接

```bash
# 1. 执行者交出产物，主控派独立复核者（只读子 agent），把它的回复原文存成 r.md
# 2. 记录
python3 review_gate.py record --stage 分镜 --dir 第3集/复核 \
  --report r.md --product 第3集/3_分镜.md \
  --basis 第3集/3_丰富稿.md '00_项目/资产登记表.md#林晚,旧仓库' \
  --mode independent

# 3. 下一步开工前检查（换了对话不记得列过哪些文件，用 --from-record）
python3 review_gate.py check --stage 分镜 --dir 第3集/复核 --from-record
```

## check 的结果怎么处理

| 状态 | 意思 | 谁处理 |
|---|---|---|
| PASS | 放行 | — |
| RULED | 负责人裁决放行 | — |
| MISSING | 没有复核记录 | 主控派复核 |
| STALE | 复核后文件改过 | 主控重新派复核（可做增量复核） |
| REVISE | 有问题要改 | 原执行者改完再派 |
| UNPARSEABLE | 报告里找不到唯一一行结论 | 主控重派，要求按格式写 |
| NEEDS_EVIDENCE | 证据不够 | 主控补证据（跑脚本、抽帧）再派 |
| NEEDS_DECISION | 规则冲突或要人定 | 先查规则台账，台账答不了再问负责人 |
| LIMIT | 连续三轮 REVISE | 停下，交负责人 |
| SELF_REVIEW | 作者自审的 PASS | 不放行，改派独立复核 |

## 负责人裁决

负责人说“就这样用”“不同意复核意见”时，把原话记下来，不要替他写 PASS：

```bash
python3 review_gate.py ruling --stage 分镜 --dir 第3集/复核 \
  --quote "节点7保留，剪辑时处理" --source "对话 10-24 14:05" \
  --product 第3集/3_分镜.md
```

所审文件再变，裁决也失效。

## 共享大表只算相关的行

`资产登记表.md` 这类整个项目共用的表，写成 `路径#关键词1,关键词2`，只对含这些词的行算哈希。别的集改了表里别的行，这一集的记录不会失效。

## --mode 如实填

- `independent`：只读子 agent，独立上下文。
- `degraded`：找不到只读 agent，用通用 agent 加提示词约束，没有工具隔离。
- `self`：作者自己审的。可以记，但不能放行。

## 复核报告格式（给复核者）

报告全文只能有一行以 `- 结论：`（英文 `- Verdict:`）开头：

```markdown
### 问题
1. 位置：第3集/3_分镜.md 第 88 行（节点 07）
   依据：资产登记表“林晚 / 常服”
   看到：写成“黑色风衣”，登记图是灰色针织外套
   影响：生成后人物换装，和前后节点接不上
   改法：按登记表改外观词
   归属：分镜
### 逐项检查
| 编号 | 结果 | 证据 |
|---|---|---|
| S01 | 过 | 第 12–30 行，节点 01–03 已对照丰富稿第 2 场 |
### 复核结论
- 结论：REVISE
```
