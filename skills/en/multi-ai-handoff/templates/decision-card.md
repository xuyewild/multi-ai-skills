# Decision Card Template

Use this when the owner needs to decide. At most four questions at a time. A reply like "1A 2B" is enough.

```text
1. In node 07 shot 3 the cut comes one second early. What should we do?
   A. Keep it, handle it in editing (recommended)
   B. Change parameters and regenerate this node (about 120 credits)
   C. Send it back to the shot list to rewrite the wording
   D. None of these, let me explain
2. Is this new outfit permanent, or only for this episode?
   A. Permanent, add it to the asset register
   B. One-off, generate from a text description
```

How to write it:

- Number each question. Write each option as "what happens if chosen", one per line.
- Put the recommended option first and mark it "(recommended)". Mark multi-select questions "multiple allowed". Write the cost where there is one.
- Ask only what the human really must decide. Do not ask what the rule ledger, project records, or usual practice can settle. State one assumption at the start of the delivery instead.
- Write what the owner has answered into the project files (rule ledger or notes), so it is not asked again.
